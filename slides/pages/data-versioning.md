# Data Versioning

<v-clicks depth=2>

* MLflow gives us traceability
* But how do we reproduce a result when the underlying data changes?
  * History tables instead of in-place updates
  * Data version control — e.g. [DVC](https://dvc.org/) / [git-lfs](https://git-lfs.com/)
  * Tagged with experiments for full reproducibility

</v-clicks>
